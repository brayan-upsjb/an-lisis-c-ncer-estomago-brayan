# Sistematización de Métodos Estadísticos: Cáncer de Estómago

## Descripción del proyecto
Repositorio destinado a la documentación y sistematización del proceso de análisis estadístico aplicado a datos sobre cáncer de estómago (cáncer gástrico), utilizando documentos reproducibles.

## Autor
- Quispe Gutierrez, Brayan Jesus

## Objetivo general
Sistematizar los procedimientos de análisis estadístico sobre variables clínicas y epidemiológicas del cáncer de estómago para facilitar la interpretación, organización y reproducción de los resultados.

## Objetivos específicos
- Organizar y preparar bases de datos.
- Aplicar métodos estadísticos descriptivos e inferenciales.
- Elaborar tablas y gráficos estadísticos.
- Interpretar los resultados obtenidos.
- Documentar los procedimientos de análisis.

## Metodología
1. Recolección de datos.
2. Limpieza y preparación de datos.
3. Análisis estadístico descriptivo.
4. Análisis estadístico inferencial.
5. Visualización de resultados.
6. Interpretación y conclusiones.
